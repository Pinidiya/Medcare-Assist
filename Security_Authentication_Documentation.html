1 Password Encryption (Hashing)

🔐 Algorithm: PASSWORD_ARGON2ID

Argon2id is the strongest password hashing algorithm available in PHP. It was the winner of the Password Hashing Competition (PHC) and is resistant to both GPU-based brute-force attacks and side-channel (timing) attacks.

How it works: Converts plain-text passwords into irreversible, one-way hashes using memory-hard computation. Even if the database is leaked, attackers cannot recover original passwords.

4 Cryptographically Secure Token Generation

🎲 CSPRNG: random_bytes() + bin2hex()

Used to generate cryptographically secure random tokens for password reset. These tokens are unpredictable and impossible to guess.

// Generates a 64-character hexadecimal token
$token = bin2hex(random_bytes(32));

⏰ Token Expiry (Time-Limited Tokens)

Password reset tokens expire after 5 minutes to prevent replay attacks.

-- Setting expiry (models/User.php)
UPDATE users SET reset_token = :token, 
    reset_token_expiry = DATE_ADD(NOW(), INTERVAL 5 MINUTE) WHERE email = :email

-- Validating expiry
SELECT user_id FROM users WHERE reset_token = :token AND reset_token_expiry > NOW()

-- Clearing after use (one-time use)
UPDATE users SET password_hash = :hash, reset_token = NULL, reset_token_expiry = NULL

5 SQL Injection Prevention

🛡️ PDO Prepared Statements with Parameter Binding

Every single database query in the project uses PDO Prepared Statements. This completely prevents SQL Injection attacks by separating SQL code from user data.

// ✅ SAFE — Used throughout the entire project (Parameterized)
$stmt = $db->prepare("SELECT * FROM users WHERE email = :email");
$stmt->execute([':email' => $email]);

// ❌ UNSAFE — NEVER used in this project (String concatenation)
$stmt = $db->query("SELECT * FROM users WHERE email = '$email'");

8 Database Transaction Security (Concurrency Control)

🔒 SELECT ... FOR UPDATE (Row-Level Locking)

Prevents race conditions when multiple users try to modify the same record simultaneously (e.g., two pharmacists claiming the same reservation, or concurrent payment processing).

$db->beginTransaction();

// Lock the row — other transactions must wait
$stmt = $db->prepare(
    "SELECT pharmacy_id, status FROM reservations 
     WHERE reservation_id = :rid FOR UPDATE"
);
$stmt->execute([':rid' => $reservationId]);

// ... safely modify data ...

$db->commit();  // Release lock
